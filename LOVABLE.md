# SEI Guardian Vigil - Lovable Configuration

## Project Structure
This is a Vite + React + TypeScript project with the following key characteristics:

- **Framework**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist/`
- **Entry Point**: `src/main.tsx`
- **Root Component**: `src/App.tsx`

## Build Requirements
- Node.js 18+ 
- npm or yarn
- All dependencies are in `package.json`

## Key Features
- SEI Blockchain integration
- Agent management system
- Security monitoring dashboard
- Real-time threat intelligence

## Build Process
1. Install dependencies: `npm install`
2. Build for production: `npm run build`
3. Output will be in `dist/` directory

## Lovable Integration
- Uses `lovable-tagger` plugin for component analysis
- Builds successfully with all dependencies
- Output includes proper asset bundling
