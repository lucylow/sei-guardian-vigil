# SEI Guardian Vigil - Project Documentation

Welcome to the SEI Guardian Vigil project! This repository contains a comprehensive blockchain security and AI agent system built on the SEI blockchain.

## 📁 Project Structure

```
sei-guardian-vigil/
├── 📱 frontend/                 # React frontend application
├── 🔧 backend/                  # Node.js backend services
├── ⛓️  contracts/               # Smart contracts (Solidity)
├── 🤖 agents/                   # AI agent implementations
├── 📚 docs/                     # Project documentation
├── 🧪 tests/                    # Test suites
├── 🛠️  scripts/                 # Deployment and utility scripts
├── 🔐 blockchain-watch/         # Blockchain monitoring tools
├── 🎮 demos/                    # Demo applications and examples
└── 📋 config/                   # Configuration files
```

## 🚀 Quick Start

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm run dev
   ```

3. **Deploy Smart Contracts**
   ```bash
   npx hardhat deploy
   ```

## 🔧 Technology Stack

- **Frontend**: React + TypeScript + Tailwind CSS
- **Backend**: Node.js + Express
- **Blockchain**: SEI Network + Hardhat
- **AI**: Custom AI agents + MCP integration
- **Database**: Supabase
- **Testing**: Jest + Hardhat testing
